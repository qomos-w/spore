# spore-gen-go-types

Renders Spore DSL value-type declarations (struct objects, enums) from `.spore`
files into Go source files, plus a registry file that maps schema IDs to Go
types.

## Install

```bash
go install github.com/qomos-w/spore/cmd/spore-gen-go-types@latest
```

Or build locally from the spore repo:

```bash
go build -o ./bin/spore-gen-go-types ./cmd/spore-gen-go-types
```

## Usage

```bash
spore-gen-go-types \
    --in       myxos/schemas \
    --out-dir  myxos/pkg/domain/gen \
    --package  gen
```

| Flag | Default | Meaning |
|---|---|---|
| `--in` | _(required)_ | Input `.spore` file or directory (walked recursively). |
| `--out-dir` | _(required)_ | Output directory root. Created if it does not exist. |
| `--package` | _(required)_ | Go package name for all emitted files. |
| `--header` | `// Code generated by spore-gen-go-types. DO NOT EDIT.` | Comment header prepended to every generated file. |
| `--no-registry-init` | `false` | Omit the spore/schema import and `init()` registry blocks (dependency-free targets, e.g. the plugin SDK). |
| `--emit-components` | `false` | Emit `runtime.Component[T]` descriptor vars for `@component` structs and the codegen registry table consumed by `World.AddRegistry`. |
| `--no-initialisms` | `false` | Export field names in plain PascalCase (`pawnId` → `PawnId`) without ALL_CAPS initialisms. |

## Output layout

```
<out-dir>/agent.gen.go        # from agent._300.spore
<out-dir>/agent.chat.gen.go   # from agent.chat._370.spore
<out-dir>/registry.gen.go     # global ID -> type map
```

Non-struct objects (classes, interfaces) are skipped silently; enum
declarations are emitted as named Go int types with typed constants.

Parsing goes through the schema-only frontend parser
(`internal/script/frontend`), never the script execution runtime.

## Calling the package directly

Embedders **outside** the spore module drive generation through the public
`gen/render` façade: `render.RenderGoTypes`, `render.RenderGoTypesRegistry` and
`render.AssignSequentialSchemaIDs` re-export this generator over the same
options contract, so no internal import is required. Programs inside the spore
module may still import `internal/gen/go-types` directly.

```go
import (
    "github.com/qomos-w/spore/gen/render"
    "github.com/qomos-w/spore/schema"
)

render.AssignSequentialSchemaIDs(objs, "agent._300.spore")

src, err := render.RenderGoTypes(objs, render.GoTypesOptions{Package: "gen"})
reg, err := render.RenderGoTypesRegistry(entries, render.GoTypesOptions{Package: "gen"})
```
